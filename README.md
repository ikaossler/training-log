# Training Log

A training log where you can add, view, edit and delete training types, and filter them by status.

**Live:** https://training-log-pearl-alpha.vercel.app
**GitHub:** https://github.com/ikaossler/training-log

## Handle

My handle in the Shelf API is `ika-o`. All my training items are saved under it.

## Running the app

```bash
npm install
npm run dev
```

Then open the address shown in the terminal, usually http://localhost:5173.

## Features

- List of all training items, with status filters (All, Want to try, Active, Paused, Quit)
- A page for each item with its details
- Change status and rating, and delete an item
- A form to add a new item
- Loading indicator and error messages from the API

## Tech

- React, TypeScript and Vite
- React Router for navigating between pages
- Shelf API for data (GET, POST, PATCH and DELETE)
